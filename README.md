# Kontor Shop – Support

Fehler melden und Wünsche einreichen für **Kontor Shop**, den Vereinsshop für WordPress.
Bug reports and feature requests for **Kontor Shop**, the club shop for WordPress.

- **Fehler melden / Report a bug:** am einfachsten direkt im Plugin unter *Kontor Shop → Protokolle → Problem melden*. Dort wird ein Diagnosebericht ohne Kundendaten automatisch eingefügt.
  Easiest from inside the plugin: *Kontor Shop → Logs → Report a problem* – a diagnostics report without customer data is filled in for you.
- **Wunsch / Feature request:** [neues Issue](../../issues/new/choose)
- **Ohne GitHub-Konto / No GitHub account:** wordpress@veyra-assistant.com

Meldungen hier sind öffentlich. Bitte keine Passwörter, Zugangsdaten oder Kundendaten einfügen.
Reports here are public. Please never paste passwords, credentials or customer data.

Website: https://veyra-assistant.com/kontor-shop/
